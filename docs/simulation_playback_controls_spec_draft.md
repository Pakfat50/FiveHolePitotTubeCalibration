# シミュレーション再生操作機能 仕様案

## 1. 目的

シミュレーション画面のアニメーションに、一時停止、再生、および較正点単位のシーク機能を追加する。

本仕様案は、既存のシミュレーション表示内容・較正点計算・Gコード生成処理を変更せず、シミュレーション画面の再生操作性だけを向上させることを目的とする。

## 2. 適用範囲

### 2.1 対象

- シミュレーション画面のアニメーション再生制御
- シミュレーション画面の既存プログレスバー
- シミュレーション画面に追加する再生/一時停止ボタン
- 現在較正点表示および再生進捗表示

### 2.2 対象外

- 較正点の生成方法
- AoA/AoSからZ/Aへの座標変換
- X/Y補正および可動範囲判定
- Gコード生成
- メインGUIの較正点マップ
- 設定保存・読込
- シミュレーション画面以外のGUI

## 3. 既存仕様との関係

以下の既存要求は維持する。

- シミュレーション全体の再生時間は約10秒とする。
- Gコードの保持時間はシミュレーション再生時間へ反映しない。
- 較正点は走査順に1点ずつ表示する。
- 横面図、正面図、較正点マップの現在点表示は同一較正点に同期する。
- シミュレーション画面には現在較正点番号、AoA、AoS、X、Y、Z、A、可動範囲状態および再生進捗を表示する。
- 較正点マップの進捗表示は「現在の較正点 / 全較正点」とする。

既存の「全較正点表示完了後に先頭へ戻って繰り返す」動作は、本機能追加後は廃止し、最終較正点で停止する。

## 4. 機能要求

### REQ-SIM-007（再生開始）

シミュレーション開始時、シミュレーションは先頭の較正点から再生を開始しなければならない。

開始時の状態は再生中とし、操作ボタンには一時停止ボタンを表示しなければならない。

### REQ-SIM-008（一時停止）

再生中に一時停止ボタンを押した場合、シミュレーションは現在の較正点を保持したまま停止しなければならない。

一時停止中は、操作ボタンに再生ボタンを表示しなければならない。

### REQ-SIM-009（再生再開）

一時停止中に再生ボタンを押した場合、現在位置から再生を再開しなければならない。

ただし、最終較正点で停止している場合は、先頭の較正点へ移動して再生を開始しなければならない。

### REQ-SIM-010（シーク）

シークバーをドラッグすることにより、任意の較正点へ移動できなければならない。

シーク位置は連続した時間位置ではなく、較正点単位で決定しなければならない。

### REQ-SIM-011（シーク時の自動一時停止）

再生中にシークバーの操作を開始した場合、シミュレーションは自動的に一時停止しなければならない。

シーク操作中および操作終了後は、選択された較正点を表示し、再生ボタンを表示しなければならない。

### REQ-SIM-012（シーク位置の即時反映）

一時停止中またはシーク操作中にシーク位置が変更された場合、以下の表示を選択された較正点へ即座に更新しなければならない。

- 横面図
- 正面図
- 較正点マップ上の現在点強調
- 現在較正点番号
- AoA、AoS、X、Y、Z、A
- 可動範囲状態
- 「現在の較正点 / 全較正点」の進捗表示

### REQ-SIM-013（再生完了）

最終較正点の表示が完了した場合、シミュレーションは自動的に停止し、最終較正点を表示した状態で待機しなければならない。

再生完了後に自動的に先頭へ戻って再生してはならない。

再生完了後は再生ボタンを表示しなければならない。

### REQ-SIM-014（既存プログレスバーの置換）

既存のプログレスバーはシークバーへ置き換えなければならない。

既存プログレスバーとシークバーを同時に表示してはならない。

シークバーは、現在の較正点および全較正点に対する進捗を表すものとする。

### REQ-SIM-015（シークバー操作性）

シークバーは、ドラッグ操作しやすい十分な大きさのつまみを持たなければならない。

シークバーは、マウスによるつまみのドラッグに加えて、トラック上のクリックでも該当位置へ移動できることが望ましい。

シークバーは、較正点単位で操作できなければならない。

### REQ-SIM-016（操作ボタン表示）

シミュレーション画面には、シークバーの横に再生状態操作ボタンを1個配置しなければならない。

ボタン表示は状態に応じて以下のとおり切り替える。

| 状態 | ボタン表示 | 押下時の動作 |
|---|---|---|
| 再生中 | 一時停止「Ⅱ」 | 現在位置で一時停止 |
| 一時停止中 | 再生「▶」 | 現在位置から再生再開 |
| 最終位置で停止中 | 再生「▶」 | 先頭へ移動して再生開始 |

専用の巻き戻しボタンおよび時間単位のスキップボタンは設けない。

## 5. UI配置

既存プログレスバーの位置をシークバーへ置き換え、シークバーの横に操作ボタンを追加する。

その他のシミュレーション画面の配置、サイズ、横面図、正面図、較正点マップ、状態表示領域は変更しない。

想定レイアウトは以下のとおり。

```text
[          較正点シークバー          ] [Ⅱ / ▶]
              現在の較正点 / 全較正点
```

## 6. シークバー実装方針

シークバーには、ドラッグ可能なつまみを持つTkinterのスケールウィジェットを使用する。

- 最小値：先頭較正点のインデックス
- 最大値：最終較正点のインデックス
- 分解能：1
- 現在値：現在較正点のインデックス
- つまみ：標準より大きく設定し、マウスで操作しやすくする
- 値変更時：対応する較正点を即座に描画する
- 再生中の値変更開始時：再生を停止する

シークバーの値は、既存の `SimulationController._frame_at` が扱う正規化進捗値へ変換して利用してよい。ただし、画面上の操作および表示は較正点インデックスを基準とする。

## 7. 状態遷移

| 現在状態 | 操作 | 次状態 | 表示 |
|---|---|---|---|
| 未再生 | シミュレーション開始 | 再生中 | 先頭点、Ⅱ |
| 再生中 | 一時停止 | 一時停止中 | 現在点、▶ |
| 再生中 | シーク操作開始 | 一時停止中 | 選択点、▶ |
| 一時停止中 | シーク操作 | 一時停止中 | 選択点、▶ |
| 一時停止中 | 再生 | 再生中 | 現在点から再生、Ⅱ |
| 最終位置停止中 | 再生 | 再生中 | 先頭点から再生、Ⅱ |
| 再生中 | 最終点到達 | 最終位置停止中 | 最終点、▶ |

## 8. 制約

- 本機能の変更対象は、原則としてシミュレーションモジュールだけとする。
- シミュレーションモジュール以外の変更が必要になった場合は、実装前に確認を受ける。
- 既存プログレスバーを残したままシークバーを追加してはならない。
- シミュレーション画面のレイアウト変更は、シークバーへの置換と操作ボタンの追加に限定する。
- シミュレーション再生中も、横面図・正面図・較正点マップの同期表示を維持する。
- 実際のGコード生成処理およびCalibrationPlanの内容を変更してはならない。

## 9. 受入条件

1. シミュレーション開始時に先頭から再生される。
2. 再生中に一時停止でき、現在の較正点が保持される。
3. 一時停止中に再生を再開できる。
4. 再生中にシーク操作を開始すると自動停止する。
5. シークバーで任意の較正点へ移動できる。
6. シーク位置の変更が横面図、正面図、較正点マップ、数値表示へ即時反映される。
7. 再生完了後は最終位置で停止し、自動ループしない。
8. 最終位置で再生ボタンを押すと、先頭から再生される。
9. 既存プログレスバーが表示されず、シークバーだけが表示される。
10. シークバーのつまみを容易にドラッグできる。
11. シミュレーション画面以外の機能に影響がない。
12. 既存のシミュレーション表示内容および約10秒の再生時間が維持される。
