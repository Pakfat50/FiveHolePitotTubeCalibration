5孔ピトー管較正 / Python 3.10以降、Tkinter、NumPy、SciPy
同じPython環境に numpy scipy を導入して python app.py で起動します。
Windowsでは環境のpython.exeを指定できます。オフライン環境では適合するwheelが必要です。

AirDataMonitorのCSVを追加し、ファイルごとの基準動圧 [Pa] を指定します。
静定幅は標準偏差でなく区間全体の最大－最小です。初期値は0.3°・1秒で、
前後各0.15秒を捨てます。実測の保持時間、姿勢ノイズ、配管応答に合わせてください。
静定区間CSVの開始・終了時刻は平均に使った両端です。5列のセンサー値または
時刻が欠測の行、時刻が戻る区間、50ms超の断絶は分けて処理します。
ゼロ点調整済みの装置Pitch・RollとGコードの回転方向が一致すると仮定します。
機体軸に対する流れとして軸成分を x=cos(Pitch), y=sin(Pitch)sin(Roll),
z=sin(Pitch)cos(Roll) と置きます。α=atan2(z,x), β=atan2(y,hypot(x,z))。
正面流ではどのロール値も同じ流向になります。

各静定区間の差圧平均から a=AoA/Total, s=AoS/Total, k=基準動圧/Total を作ります。
実測(α,β)から(a,s,k)を薄板スプラインで補間し、実測角の凸包内の等間隔格子で評価します。
内部の未計測領域は補間です。格子を細かくしても独立な実測点は増えません。
低角域・中央全圧孔が最大、Total>0の試験データを使用してください。
推定は試験でカバーした流向・差圧比・風速の範囲内で行います。
係数CSVの各行の2つの指数(i,j)に対し、基底は a^i s^j です。
α[°], β[°], k の各列を基底と積和し、動圧は Total×k [Pa] とします。
点一覧のfit列は学習点での再現値です。独立精度の確認には別走査で検証してください。

グラフ表示（Matplotlibが必要です）
  初回はアプリと同じPython環境に python -m pip install numpy scipy matplotlib で導入します。
  「時系列」内のCSV名タブを選ぶと、上にロール・ピッチ、下にTotal・AoA・AoSの差圧が表示されます。
  緑の帯は前後を除外した後に実際に平均へ使う区間です。横軸は先頭からの経過秒で、
  ツールバーでズームすると両段が連動します。時刻が巻き戻るときは前区間の直後に並べます。
  「較正して曲面を表示」で係数CSVの保存前にも3Dを確認できます。
  表示する面を選択し、左ドラッグで回転、右ドラッグでズームできます。
  横2軸はどの面もAoA/TotalとAoS/Total。高さは迎角[deg]、横滑り角[deg]、
  または動圧補正係数 q_ref/Total [-] です。赤点は各静定区間の観測値です。

推定値と真値・RMSE
  較正後、4番目の「推定値と真値」内で比較するCSV名のタブを選びます。3段のグラフは
  各サンプルの3差圧から推定したAoA・AoS・動圧と、同じ行の装置姿勢から求めた
  TM765の迎角・横滑り角、ファイルに指定した基準動圧を共通時間軸で示します。
  「入力・較正」の表にはCSV名・基準動圧・評価区間・3出力のRMSEを示します。
  複数CSVのときは全サンプルで集計した「全CSV」行も表示します。
  「全有効区間」は移動中も含み、「採用した静定区間」は緑の帯の中だけです。
  Totalが0以下の行や欠測値を含む比較ペアは対象外です。較正に使用した同じログでの再現誤差です。

複数の動圧での較正
  「CSV追加（複数選択可）」で複数ログを選び、それぞれの基準動圧をPaで入力します。
  各ファイルのAoA/Total、AoS/Total、基準動圧/Totalを用い、全静定点から共通の係数を1組求めます。
  「時系列」「推定値と真値」のCSVタブは連動します。矢印でも前後のCSVへ移動できます。
